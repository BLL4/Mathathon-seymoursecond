\section{Verification and scope of this exposition}
This exposition is a modified version of the supplied OpenAI preprint,
licensed under Apache 2.0 in the parent repository. The main proof text and
bibliography are derived from that source. The reading guide, explanatory
paragraphs, new figures, presentation, experiments, and Lean development
are additions. Historical attributions and external weighted equivalences
are retained as source attributions; their original papers have not been
independently audited here.

The main proof has three logically separate dependencies:
\begin{enumerate}
\item Minimality supplies a subset deficit, and blowup amplifies its integer
slack. Deletion is always restarted from the original minimal graph.
\item Pruning applies to arbitrary finite relations. Its proof uses real
linear algebra, simultaneous nonvanishing of finitely many minors, and the
matching--cover theorem (whose alternating-path proof is included).
\item The extremal argument uses orientation to make the diagonal pair
compatible, and positive indegrees to ensure its fibers are proper.
\end{enumerate}
The ledger accompanying this document records checks of these interfaces.
Finite experiments are regression checks for definitions and charging;
they do not establish the theorem for arbitrary order. The Codex component development proves selected set-image identities,
the exact maximum-support-rank kernel lemma, and the restriction of corner
equations to auxiliary matrices. It constructs normalized lifts from
spanning columns and combines them into a conditional kernel-dimension
bound. It also checks simultaneous nonvanishing of polynomial minors and
a matching certificate for a sparse minor. These independent component
checks are not by themselves a complete graph proof.

\paragraph{A complete, attributed reference proof.}
A later source snapshot from Claude Opus 5.5's formalization in the other
work directory is included unchanged under \texttt{lean/reference/}.
All twelve reference modules were compiled anew here; no compiled objects
were copied from that project. The resulting full theorem was then
translated to this exposition's image convention by
\texttt{ReferenceBridge.lean}. Both the reference theorem and the bridge
print only Lean's standard axioms: propositional extensionality, classical
choice, and quotient soundness. No pruning or graph-reduction statement is
an unproved hypothesis of this final theorem.

This is a reused and independently rebuilt reference contribution, not an
independently authored Codex formalization. The reference uses generic
coefficients in the rational function field $\mathbb Q(x)$, rather than
choosing a simultaneous real point. The graph conclusion and neighborhood
conventions agree with the supplied preprint. The source manifest records
hashes and attribution; the accompanying status document records the
remaining frontier of the separate Codex development.

\paragraph{A useful consequence to keep separate from the core.}
The directed-cycle corollaries use only the proved second-neighborhood
assertion and a partition of the vertex set. Their Lean verification now
reuses the cycle companion from the DeepSeep4.1 rewrite, with checked
neighborhood-definition bridges and the good vertex supplied by the full
reference theorem. The weighted forms additionally
use the externally cited equivalences and Farkas alternative. A reader
checking the new pruning argument need not accept those external inputs to
check the unweighted implication. The normalized weighting in the second
weighted form may have zero entries; strict positivity is not asserted.
