## What each frame is for

The deck is not the paper read aloud. It carries the same five steps with the same
notation, one idea per frame, and every frame ends with a one-line takeaway. Frames 6–17 are the
proof; frames 2–5 set the problem and the map; frames 19–21 are consequences and summary, and can be
cut to shorten the talk. If ten minutes are cut, drop frames 9, 11, 14, 17, 19 and 20; the remaining
frames still form a complete argument with the pruning lemma stated and used as a black box.
